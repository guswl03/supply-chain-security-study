# SW 공급망 보안 5주 스터디

개발, 클라우드, AI, 네트워크 관점에서 소프트웨어 공급망 보안을 단계적으로 학습하는 5주 과정입니다.

## 학습 목표

5주가 끝났을 때 다음 질문에 답할 수 있는 수준을 목표로 합니다.

- SW 공급망은 어떤 참여자와 단계로 구성되는가?
- 개발, 클라우드, AI, 네트워크 영역에는 각각 어떤 공급망 위험이 있는가?
- 취약점, 악성 구성요소, 변조, 설정 오류는 어떻게 다른가?
- SBOM, 서명, 출처 증명, 접근통제는 각각 무엇을 보장하는가?
- 4개월 프로젝트로 해결할 문제를 어떻게 정의하고 평가할 것인가?

## 진행 방식

- 권장 시간: 주 5~7시간
- 이론 40%, 사례 분석 30%, 실습 30%
- 모든 실습은 본인 소유의 로컬·격리 환경에서만 수행합니다.
- 실제 악성코드 대신 무해한 모의 파일과 테스트 패키지를 사용합니다.

## 매주 공통 산출물

각 주차 폴더의 안내에 따라 다음 네 가지를 남깁니다.

1. 핵심 개념을 자신의 말로 정리한 1쪽 노트
2. 실제 사고 또는 가상 시나리오 분석 1건
3. 안전한 미니 실습 결과
4. 아직 답하지 못한 질문 3개

학습 기록은 [주간 학습 기록 양식](templates/weekly-note.md)을 복사해 작성합니다.

## 권장 학습 순서

```text
전체 구조 이해
→ 공격 지점 식별
→ 예방·보호 통제 이해
→ 가시성·탐지·대응 연결
→ 4개월 프로젝트 문제 정의
```

도구 사용법을 외우기보다 다음 연결을 매주 반복해서 확인합니다.

```text
자산 → 참여자 → 신뢰 관계 → 위협 → 통제 → 측정 방법
```

## 완료 기준

- [ ] 공급망 데이터 흐름도를 그릴 수 있다.
- [ ] 영역별 공격 시나리오를 최소 1개씩 설명할 수 있다.
- [ ] 예방·탐지·대응 통제를 구분할 수 있다.
- [ ] SBOM이 보장하는 것과 보장하지 않는 것을 설명할 수 있다.
- [ ] 프로젝트 후보 3개를 동일한 기준으로 비교할 수 있다.
- [ ] 최종 후보 1개의 위협모델과 평가계획을 작성했다.
