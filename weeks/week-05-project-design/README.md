# 5주차: 통합 위협모델과 프로젝트 주제선정

난이도: 중급

## 이번 주 질문

> 네 영역이 연결된 공급망에서 4개월 동안 어떤 문제를 해결하고 어떻게 효과를 증명할 것인가?

## 통합 시나리오

다음 가상 서비스를 기준으로 위협모델을 작성합니다.

```text
개발자
→ Git 저장소
→ 외부 패키지·AI 모델
→ 클라우드 CI/CD
→ 컨테이너 레지스트리
→ 클라우드 배포
→ 네트워크
→ 사용자
```

## 작성할 위협모델

1. 보호할 자산
2. 참여자와 책임
3. 데이터 및 산출물 흐름
4. 신뢰 경계
5. 공격자와 공격 목표
6. 가능한 공격 경로
7. 예방·탐지·대응 통제
8. 남아 있는 위험

## 프로젝트 후보 예시

### 후보 A: SBOM 품질 검증

- 문제: 도구마다 누락·중복·버전 오류가 발생
- 평가: 정확도, 누락률, 중복률, 분석시간

### 후보 B: 런타임 기반 취약점 우선순위화

- 문제: 포함된 패키지와 실제 사용되는 패키지를 구분하기 어려움
- 평가: 경고 감소율, 실제 사용 구성요소 식별률

### 후보 C: 빌드 산출물 출처와 무결성 검증

- 문제: 정상 소스가 빌드·배포 과정에서 변조될 수 있음
- 평가: 변조 시나리오 탐지율, 검증시간, 실패 원인 설명력

### 후보 D: 클라우드·AI 공급망 통합 인벤토리

- 문제: 코드, 이미지, 모델, 데이터의 소유자와 배포 위치가 분리됨
- 평가: 자산 식별률, 변경 추적률, 영향 분석시간

## 후보 평가표

각 항목을 1~5점으로 평가합니다.

| 기준 | 설명 |
|---|---|
| 문제의 현실성 | 실제 현장에서 반복되는 문제인가? |
| 4개월 구현 가능성 | 범위와 기술 난이도가 적절한가? |
| 데이터 확보 | 안전한 실험 자료를 구할 수 있는가? |
| 측정 가능성 | 전후 효과를 숫자로 평가할 수 있는가? |
| 차별성 | 기존 도구의 공백을 다루는가? |
| 시연 가능성 | 공격과 방어를 안전하게 보여줄 수 있는가? |
| 관심과 성장성 | 팀이 4개월 동안 몰입할 수 있는가? |

## 최종 산출물

- 공급망 데이터 흐름도
- 위협모델 1부
- 프로젝트 후보 비교표
- 최종 문제정의서
- 4개월 구현 범위와 제외 범위
- 평가 지표와 안전한 실험 계획
- 멘토에게 확인할 질문 5개

최종 문제정의는 [프로젝트 주제선정 양식](../../templates/project-proposal.md)을 사용합니다.
