# 2주차: 공격면과 대표 공격

난이도: 초급

## 이번 주 질문

> 공격자는 어느 신뢰 관계를 이용해 정상적인 제품이나 업데이트처럼 보이게 하는가?

## 핵심 개념

- 공격 표면, 공격 경로, 신뢰 악용
- 취약한 구성요소와 악성 구성요소의 차이
- 계정 탈취, 변조, 의존성 혼동, 타이포스쿼팅
- 빌드 시스템 및 업데이트 서버 침해
- 제3자·제4자 위험

## 카테고리별 학습

### 개발

- 개발자 계정 및 토큰 탈취
- 악성 커밋과 코드 리뷰 우회
- 공개 패키지 저장소 공격
- CI/CD 워크플로와 빌드 서버 변조

### 클라우드

- 공개 컨테이너 이미지와 레지스트리 위험
- 잘못된 IAM 권한과 장기 자격증명
- 외부 Terraform 모듈 등 IaC 의존성
- 관리형 서비스와 SaaS 연쇄 위험

### AI

- 데이터 오염과 백도어 데이터
- 출처가 불분명한 모델과 피클 파일
- 모델 허브 계정 탈취
- 외부 AI API 또는 플러그인 의존성

### 네트워크

- 업데이트 다운로드 경로 가로채기
- DNS·저장소 미러 변조
- 인증서와 서명 검증 실패
- 협력사 원격접속 경로 악용

## 사례 학습

다음 중 두 건을 선택합니다.

- SolarWinds: 빌드·업데이트 경로 침해
- Codecov: CI/CD 스크립트와 인증정보 유출
- 3CX: 연쇄 공급망 침해
- XZ Utils: 오픈소스 신뢰 관계 악용

사례마다 `진입점 → 악용한 신뢰 → 변조 대상 → 전파 → 영향 → 가능한 통제`를 작성합니다.

## 미니 실습

1주차 공급망 지도에 공격 경로 세 개를 추가하고 공격 트리로 표현합니다. 실제 공격은 수행하지 않습니다.

## 완료 기준

- [ ] 취약점과 의도적인 악성 변조를 구분할 수 있다.
- [ ] 네 카테고리별 공격 시나리오를 하나씩 작성했다.
- [ ] 대표 사고 두 건을 동일한 양식으로 비교했다.
- [ ] 보호 우선순위가 높은 자산 세 개를 정했다.
