# 3주차: 예방 통제와 무결성

난이도: 초중급

## 이번 주 질문

> 신뢰를 가정하는 대신 출처와 무결성을 어떻게 검증할 수 있는가?

## 핵심 개념

- 최소 권한, 업무 분리, 다중 승인
- 해시, 전자서명, 인증서
- 재현 가능한 빌드와 출처 증명
- Secure by Design, DevSecOps, NIST SSDF
- 예방·탐지·대응 통제의 차이

## 카테고리별 학습

### 개발

- 브랜치 보호와 필수 코드 리뷰
- 의존성 버전 및 해시 고정
- CI/CD 실행 권한과 비밀정보 관리
- 빌드 산출물 서명과 검증

### 클라우드

- IAM 최소 권한과 단기 자격증명
- 컨테이너 이미지 서명 및 변경 불가능한 다이제스트
- 격리된 빌드 실행 환경
- IaC 검토와 정책 기반 배포

### AI

- 데이터셋과 모델의 출처·버전 기록
- 모델 파일 해시와 서명
- 안전한 직렬화 형식
- 학습·평가·배포 권한 분리

### 네트워크

- TLS와 상호 TLS의 역할
- 개발망, 빌드망, 운영망 분리
- 허용된 저장소와 업데이트 주소 제한
- 송신 트래픽 및 협력사 접속 통제

## 미니 실습

무해한 텍스트 파일을 빌드 산출물이라고 가정합니다.

1. 파일의 SHA-256 해시를 기록합니다.
2. 파일 내용을 변경한 후 해시가 달라지는지 확인합니다.
3. 누가, 언제, 어떤 파일을 검증했는지 기록합니다.
4. 이 방식이 보장하지 못하는 것을 세 가지 작성합니다.

## 완료 기준

- [ ] 공격 유형별 예방 통제 표를 작성했다.
- [ ] SSDF의 네 영역을 이해했다.
- [ ] 최소 권한을 네 카테고리에 적용해봤다.
